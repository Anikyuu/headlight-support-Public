# 道具ページのイラスト

19項目に各1枚。単一場面、2場面、静物、図解を混ぜ、すべて3コマにはしない。白地、細い紺の線、少ない色、余白、表情や動きのユーモアを重視する。人物を東アジア系へ偏らせず、幼い頭身や細密な水彩に寄せない。

説明文は全文を維持し、8言語の代替説明を付けた。絵に文字を入れず同じ画像を全言語で使う。

生成: 組み込みimage_gen。各画像の最終プロンプト、用途、寸法は [generation-manifest.json](generation-manifest.json)。ルーティーンは品質指摘後の余白を増やした再案、アイデアの瓶は方向確認に使用した試作を採用。ほか17点は同じ再案をスタイル参照として描き直した。過去の却下案は掲載しない。

## 手放すの差し替え

Kaiの訂正により、ため息で消える絵を、愚痴・不満・怒りを瓶へぶちまけ、満杯の瓶を爆発させて解放する3場面へ変更。`release-explosion.png` を使用し、旧 `release.png` はページでは使わない。手放すだけ横幅を広げ、動作の流れを読めるようにする。
